# App Store Privacy Answers (Draft)

Use this as your App Store Connect "App Privacy" input.

## Tracking
- Do you track users? No

## Data Collection
- Do you or third-party partners collect data from this app? No

## Privacy Nutrition Label Outcome
- Data Used to Track You: None
- Data Linked to You: None
- Data Not Linked to You: None

## Notes
- This draft assumes no analytics SDKs, no ads SDKs, no account system, and no backend telemetry.
- If you add analytics/crash/ad SDKs later, update App Privacy before submitting updates.

## Required Permissions in iOS App
- Camera access: used for capturing source photos
- Photo Library read access: used for importing photos
- Photo Library add access: used when user saves generated output
